## 🌐 How to Host on GitHub Pages

1. Push your repository code to GitHub:
   ```bash
   cd "C:\Users\nitro 5\.gemini\antigravity\scratch\RKDTiles"
   git init
   git add .
   git commit -m "Upload RKD Tiles & Bathware Link-in-Bio site"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/RKDTiles.git
   git push -u origin main
   ```
3. Go to repository **Settings > Pages**, choose `main` branch, and click **Save**.
4. Your site will be live at `https://YOUR-USERNAME.github.io/RKDTiles/`!
